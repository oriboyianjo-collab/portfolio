# איך מוסיפים חדשות לאפליקציה

החדשות בלשונית **חדשות** נקראות מהקובץ `news.json` שבתיקייה הזו.

## עריכה באתר GitHub
1. פותחים את הקובץ: https://github.com/oriboyianjo-collab/portfolio/edit/main/news.json
2. מוסיפים פריט (אפשר להעתיק את הדוגמה למטה) ולוחצים **Commit changes**.
3. אחרי דקה-שתיים החדשות מופיעות באפליקציה (בלשונית חדשות יש כפתור 🔄 לרענון).

## הפורמט
הקובץ הוא רשימה בתוך סוגריים מרובעים `[ ]`. כל פריט בתוך סוגריים מסולסלים `{ }`, ובין פריט לפריט **פסיק**.

```json
[
  {
    "כותרת": "כותרת הידיעה",
    "תאריך": "2026-10-20 18:30",
    "חברה": "טבע",
    "טקסט": "שורה ראשונה\nשורה שנייה",
    "קישור": "https://maya.tase.co.il/reports/details/1777080"
  },
  {
    "כותרת": "ידיעה נוספת",
    "תאריך": "21/10/2026",
    "טקסט": "רק כותרת, תאריך וטקסט – השאר לא חובה"
  }
]
```

- **חובה:** `כותרת` או `טקסט`. כל השאר רשות (`חברה`, `קישור`, `תאריך`).
- **תאריך:** `2026-10-20 18:30` או `20/10/2026 18:30` (השעה לא חובה). התאריך מוצג על הידיעה.
- **סדר ההצגה (מגרסה 66):** לפי זמן ההעלאה, לא לפי תאריך הפרסום. אם יש שדה `הועלה` (או `uploaded`), למשל `"הועלה": "2026-10-25 14:45"`, הוא קובע את הסדר. בלי השדה, הסדר הוא לפי הפעם הראשונה שהאפליקציה ראתה את הידיעה במכשיר (בטעינה הראשונה במכשיר חדש – לפי התאריך). מומלץ להוסיף `הועלה` לכל ידיעה חדשה.
- **שורה חדשה בטקסט:** כותבים `\n`.
- **מירכאות בתוך הטקסט:** כותבים `\"` (למשל `בע\"מ`), או משתמשים בגרש ״ במקום.
- אחרי הפריט האחרון **אין** פסיק.
- אם יש טעות בקובץ, הלשונית תכתוב "קובץ החדשות לא תקין". אפשר לבדוק את הקובץ באתר https://jsonlint.com

## תמונות
אפשר לצרף לכל ידיעה תמונה אחת או כמה.

**העלאת תמונה ל-GitHub:**
1. נכנסים לתיקיית התמונות: https://github.com/oriboyianjo-collab/portfolio/upload/main/news-images
2. גוררים את קובץ התמונה (או **choose your files**) ולוחצים **Commit changes**.
3. כדאי לתת לקובץ שם באנגלית בלי רווחים, למשל `teva-q3.jpg`.

**הוספה לידיעה ב-news.json:**
- תמונה אחת: `"תמונה": "news-images/teva-q3.jpg"`
- כמה תמונות: `"תמונות": ["news-images/a.jpg", "news-images/b.jpg"]`
- אפשר גם קישור מלא לתמונה באינטרנט שמתחיל ב-`https://`

```json
[
  {
    "כותרת": "טבע – דוח רבעון שלישי",
    "תאריך": "2026-10-21 09:15",
    "חברה": "טבע",
    "טקסט": "עיקרי הדוח בתמונות",
    "תמונות": ["news-images/teva-q3-1.jpg", "news-images/teva-q3-2.jpg"]
  }
]
```

באפליקציה: תמונה אחת מוצגת ברוחב מלא, כמה תמונות – ברשת קטנה. לחיצה על תמונה פותחת אותה במסך מלא: צביטה או הקשה כפולה להגדלה, החלקה למעבר בין תמונות, ✕ או כפתור "חזור" לסגירה.

## דוחות (לשונית חדשות ← דוחות) – הקובץ `reports.json`
עריכה: https://github.com/oriboyianjo-collab/portfolio/edit/main/reports.json · רשימה `[ ]` של פריטים, אפשר מפתחות בעברית או באנגלית:

| עברית | English | מה זה | חובה |
|---|---|---|---|
| `חברה` | `company` | שם החברה | חברה או סימול |
| `סימול` | `symbol` | סימול (AAPL, TEVA.TA) – מציג לוגו ותגית "בתיק"/"במעקב" | |
| `רבעון` | `quarter` | למשל `Q3 26` | |
| `תאריך` | `date` | `2026-10-29` | כן |
| `מועד` | `time` | `before` / `לפני` (לפני פתיחה), `after` / `אחרי` (אחרי סגירה), או שעה `16:00` | |
| `צפי_EPS` | `eps_est` | צפי רווח למניה, למשל `1.76` | |
| `EPS_בפועל` | `eps` | EPS בפועל (אחרי הפרסום) – מוצג בירוק/אדום מול הצפי + אחוז ביט/מיס (למשל `+4.1% ביט`). גם: `EPS בפועל`, `רווח למניה`, `רווח למניה בפועל`, `eps_actual`, `epsActual`, `actual_eps` | |
| `צפי_הכנסות` | `revenueEst` | צפי הכנסות, למשל `$101.9B` – מוצג ליד צפי ה-EPS (גם `צפי הכנסות` / `rev_est`) | |
| `הכנסות` | `revenue` | הכנסות בפועל (אחרי הפרסום) – בירוק/אדום מול הצפי + אחוז ביט/מיס. אפשר יחידות `M`/`B`/`T` או מיליון/מיליארד (למשל `880.2M` מול `1.02B`). גם: `הכנסות_בפועל`, `הכנסות בפועל`, `rev`, `revenue_actual`, `revenueActual`, `actual_revenue` | |
| `מדד` | `index` | מדד אחד `"S&P 500"` או כמה `["S&P 500", "Nasdaq 100"]` (אפשר גם `"S&P 500, Nasdaq 100"`). מוצג כתגית בכרטיס ובסינון | |
| `הערה` | `note` | טקסט קצר | |
| `קישור` | `link` | https://… | |

```json
[
  {"חברה": "Apple", "סימול": "AAPL", "רבעון": "Q4 FY26", "תאריך": "2026-10-29", "מועד": "after", "צפי_EPS": "1.76", "צפי_הכנסות": "$101.9B", "מדד": ["S&P 500", "Nasdaq 100", "Dow 30"]}
]
```
דוחות עתידיים מוצגים מהקרוב לרחוק, ומתחתם "דוחות שפורסמו" מהחדש לישן. פס צבעוני בצד השורה: ירוק = הכה את הצפי ב-EPS (או בהכנסות אם אין EPS בפועל), אדום = החטיא.
סינון (מצטבר): שורת ימים – הכל + כל תאריך שקיים בקובץ; שורת מדדים – הכל + כל מדד שמופיע + אחר; ו-⭐ בתיק ובמעקב.
אם אין `מדד` בפריט – האפליקציה משייכת אוטומטית לפי אחזקות תעודות הסל: S&P 500 (SPY), Nasdaq 100 (QQQ), Dow 30 (DIA), S&P 400 (MDY), S&P 600 (IJR). רק אם גם זה לא נמצא – "אחר".
שמות מוכרים מקבלים צבע קבוע: `S&P 500`, `Nasdaq 100`, `Dow 30` (או `Dow Jones`), `S&P 400`, `S&P 600`, `Russell 2000`, `Nasdaq`. כל שם אחר יוצג כמו שנכתב.

## יומן כלכלי (לשונית חדשות ← יומן כלכלי) – הקובץ `calendar.json`
עריכה: https://github.com/oriboyianjo-collab/portfolio/edit/main/calendar.json

| עברית | English | מה זה | חובה |
|---|---|---|---|
| `תאריך` | `date` | `2026-10-28` | כן |
| `שעה` | `time` | שעון ישראל, `21:00` | |
| `מדינה` | `country` | `US`, `IL`, `EU`, `DE`, `GB`, `JP`, `CN` … (מוצג דגל + כפתור סינון) | |
| `אירוע` | `event` | שם האירוע | כן |
| `תקופה` | `period` | למשל `ספטמבר · שנתי` | |
| `חשיבות` | `importance` | 1–3 (3 = ●●● חשוב, מודגש) | |
| `צפי` | `forecast` | | |
| `קודם` | `previous` | | |
| `בפועל` | `actual` | | |
| `טוב` | `good` | `true` = הנתון טוב לשוק (ירוק), `false` = רע (אדום); בלי – ללא צבע | |
| `הערה` | `note` | | |

```json
[
  {"תאריך": "2026-10-28", "שעה": "21:00", "מדינה": "US", "אירוע": "החלטת ריבית הפד", "תקופה": "FOMC", "חשיבות": 3, "צפי": "3.75%", "קודם": "4.00%"}
]
```
קובץ ריק (`[]`) או חסר – הלשונית מציגה הודעה ידידותית. שני הקבצים נקראים מחדש בכל פתיחה, כמו news.json.

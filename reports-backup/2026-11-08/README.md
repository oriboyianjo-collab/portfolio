# Completed company report connections

Backup of verified public company report sources and exact-period original PDF links, dated November8,2026. The JavaScript module and registry are standalone and are not activated in the app by this backup. Existing app behavior is unchanged.

2662 verified reusable company report directories. These are not claims of complete report histories. 309 previously verified exact-period original PDFs and4 separately verified exact-period originals are included. Missing periods remain missing. Held candidates and unverified documents are excluded.

Load report-connections.js and use ReportConnections.createRegistry(registry). resolveConnection(symbol) returns a verified directory. resolveReport(symbol, year, period) checks the legacy exact-period reports. resolveDirectReport(symbol, year, period) checks the4 additional originals. Root and direct-period readiness never imply full history.

app-report-pdf-additions.json contains4 additive links absent from the live app at verification. Publication should merge these into the existing exact-period link mapping without replacing other periods. No financial values, app redesign or automatic collection is included.
